## 数据集摘要![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/2e629d6f91b94e47a701262de16f7864.png)


本数据集为街头实景垃圾目标检测数据集，一共8773张实拍图像，单类别garbage，包含25490个垃圾标注框，同时提供YOLO、VOC、COCO三种主流标注文件，开箱即用。场景为真实街头环境，背景复杂，适合检测模型训练。

## 应用价值

1. 城市环卫巡检、街道垃圾自动识别系统开发
2. 目标检测算法训练、对比实验、论文实验
3. 智慧城市、环卫AI、城市环境监测相关研究
4. 复杂背景下小目标、杂乱目标检测算法鲁棒性测试
